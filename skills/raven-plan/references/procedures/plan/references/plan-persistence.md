# Utrwalenie i ograniczenia hosta

Kanoniczny plan to `context/changes/<id>/plan.md`. Zapisz go bez dodatkowego pytania, gdy zlecenie i host pozwalają na edycję. Brak GH nie blokuje lokalnego utrwalenia.

Jeśli host zabrania zapisów, przedstaw kompletny plan w rozmowie ze statusem `awaiting_persistence`. Nie twórz pliku zastępczego ani nie deleguj zapisu w celu obejścia ograniczenia. Wskaż konkretny brak. Po uzyskaniu możliwości zapisu sprawdź bieżący plik i różnice, utrwal zaakceptowaną treść i oblicz fingerprint. Nie powtarzaj wywiadu ani nie twórz fikcyjnej akceptacji. Sam brak historii rozmowy wymaga źródeł decyzji; nie odtwarzaj ich z domysłu.
