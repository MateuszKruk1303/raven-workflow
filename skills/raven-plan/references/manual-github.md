# Wspólne artefakty manual i auto

Oba tryby korzystają z [kontraktu pracy Git-first](../../raven-workflow/references/change-contract.md): lokalnego planu, fingerprintu, checklisty i checkpointu. Nie ma adaptera kopiującego taski GH do plików. Stara nazwa tej referencji pozostaje zgodna z odsyłaczami.

Tryb manual kończy zlecony etap. Tryb auto obejmuje zleconą orkiestrację i ograniczoną pętlę napraw. Uprawnienia publikacji, odbiór człowieka i merge są takie same. Historyczne źródła GH odczytuj tylko w zakresie potrzebnym do jawnie ustalonego mapowania.
