# Zgodność odsyłacza do kontraktu

Aktualny kontrakt to [praca Git-first](../../raven-workflow/references/change-contract.md). Czytaj go dla planów, postępu, review, uprawnień i publikacji. Ten plik zachowuje ścieżkę historycznych odsyłaczy; nie ustanawia osobnego transportu artefaktów.

Plan, checklistę i checkpoint przechowuj w repo. GitHub PR służy współpracy i CI; Project i issues są opcjonalne. Nie twórz nowych snapshotów planu ani obowiązkowych task issues. Historyczne snapshoty pozostają dowodami swojej epoki; nie migruj ich automatycznie ani nie uruchamiaj helpera snapshot_fingerprint.py do nowych planów.
