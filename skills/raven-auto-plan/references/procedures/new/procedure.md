# Tożsamość change

Ustal jeden rezultat zgodnie z [granicami change](../../../../raven-workflow/references/change-scope.md). Wykorzystaj istniejący ID lub nadaj unikalny ID w repo i utwórz `context/changes/<id>/plan.md` podczas planowania. Research/frame mogą najpierw utworzyć folder z własnym raportem. Osobny change.md, issue i Project item nie są wymagane. Zachowaj historyczne pliki, jeśli istnieją; nie wytwarzaj drugiego kanonicznego stanu.

Sprawdź kolizję ID i nie nadpisuj istniejącego zakresu. Samo utworzenie folderu nie oznacza akceptacji planu ani zgody na publikację/implementację.
