# Tożsamość change

Ustal jeden rezultat zgodnie z [granicami change](../../../../raven-workflow/references/change-scope.md). Wykorzystaj istniejący ID lub nadaj unikalny ID w repo i utwórz `context/changes/<id>/plan.md` podczas planowania. Research/frame mogą najpierw utworzyć folder z własnym raportem. Powiąż change z jednym issue GH i potwierdź jego podjęcie przed zależnym planowaniem zgodnie z [kontraktem pracy](../../../../raven-workflow/references/change-contract.md). Osobny change.md i Project item nie są wymagane. Zachowaj historyczne pliki, jeśli istnieją; nie wytwarzaj drugiego kanonicznego stanu.

Sprawdź kolizję ID i nie nadpisuj istniejącego zakresu. Samo utworzenie folderu nie oznacza akceptacji planu ani zgody na publikację/implementację.
